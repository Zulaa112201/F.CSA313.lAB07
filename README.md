## Дүгнэлт (debrief)

Хамгийн үр дүнтэй нь Couch Potato байлаа: хоосон болон хязгаарын оролтоор BUG-01 (хоосон талбартай ном нэмэгдэх) болон BUG-12 (оны шалгалтгүй) олдов. Supermodel харагдах байдлын согог (BUG-05 он таслалтай, BUG-11 Устгах товч ногоон, BUG-14 буруу мессеж) илэрсэн. Fed-Ex өгөгдлийн замд BUG-04 (нийт ном тоолуур буруу) болон BUG-08 (давхардал) олдсон. Saboteur BUG-10 (/old дээр HTTP 500), BUG-13 (HTML тэмдэгт кодлогдох) болон API (буруу JSON-д 400 биш 200 OK) илэрсэн. Charter-аас гадуур санамсаргүй олдсон зүйл бол мессежийн алдаа ба `<b>test</b>` оруулахад кодлогдох байдал юм.  Playwright автомат тест BUG-01, 04, 07, 08, 12, 14, 15-ийг баригдах байсан, учир нь тэдгээр нь тодорхой оролт, хүлээгдэж буй гаралттай. Харин BUG-05 (оны формат), BUG-11 (товчийн өнгө) нь тусгай нөхцөл бичвэл автомат тест барих боловч өнгө, харагдах байдлыг хүний нүд илүү хурдан олно. BUG-13-ыг зөвхөн тусгай тэмдэгт оруулж олсон.
